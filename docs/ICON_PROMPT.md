# Hash Checker Icon Prompt

Use the following prompt with an AI image/icon generator (e.g., Midjourney, DALL·E, Stable Diffusion) to create the application icon.

```
Design a modern, high-contrast application icon for a cross-platform hash verification tool called "Hash Checker".

Requirements:
- Shape: rounded square (app icon style) that also works as a circle crop.
- Visual cues: blend a shield or file outline with a bright checkmark to suggest integrity/confidence.
- Colour palette: deep blues/teals for the background, accented with a vibrant lime or turquoise checkmark; subtle gradient allowed.
- Style: flat or semi-flat, crisp edges, soft ambient shadow, no text.
- Output: render at 1024×1024 on transparent background; also provide 512×512 and 256×256 exports for packaging.

Convey trustworthiness, precision, and a lightweight utility feel.
```
